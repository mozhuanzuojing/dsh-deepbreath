# 息 · 呼吸能量

输入框下方的一枚「呼吸胶囊」，帮你在一整天盯屏里做几次到位的长呼气。

## 功能
- **呼吸胶囊**：常驻在消息输入框下方。平时显示「呼吸 · 今天还没做」，今天做过则显示「今天已呼吸 · 连续 N 天」。
- **呼吸卡**：点入口打开，节拍圆引导 **吸气 6 秒 → 停顿 1 秒 → 呼气 4 秒（吸气长、呼气短，吸气到底稍停）**，默认做 **3 次**（约 33 秒）。**行气导引**：吸气意想气自头顶「百会」经「下丹田」下行至脚底「涌泉」，到底略停；呼气反向，自「涌泉」经「丹田」上行回「百会」。
- **完成自动记账**：每完成一次 3 次长呼气，就向本机「记账服务」(`127.0.0.1:8765`) 追加一条完成记录；服务未启动时先存在本地，稍后自动补记。

## 怎么用
1. 需要呼吸时，点输入框下方胶囊 → 开始 → 跟着圆做 3 次长呼气。
2. 完成即自动记录，无需手动打卡。

## 重要说明与边界
- 本插件**只负责记录完成**，本身**不发送邮件**。「漏做一整天就发邮件」由同目录的**记账服务 + 每日定时检查**完成（关掉 DSH 也能跑）。
- 记账服务需在后台运行（开机自启）。若未运行，胶囊会提示"记账服务未启动"，完成记录会先本地排队、下次补记。
- 只把"完成呼吸"这一最小事件写入本机 `ledger.json`，**不读取、不外发任何会话内容**。
- 呼吸是放松练习，**不是医疗手段**；头晕/手麻即停，孕期或心肺/腹部术后请先遵医嘱。

## 更新（v0.2.0）
- 到点提醒：约 50 分钟未做，胶囊会轻脉冲提示「到点啦 · 做 3 次长呼气」；卡片内「稍后 15 分钟」可延后。
- 状态更准：区分「今天还没做 / 今天已呼吸·连续 N 天 / 记账离线 / 加载中」；完成记录分「正在记录 / 已记录 / 已存本地稍后同步」。
- 可访问：呼吸卡为对话框语义（role=dialog、焦点进入与陷阱、Esc 关闭、关闭还原焦点），尊重系统"减少动态效果"。
- 安全：补回"孕期/心肺疾病/腹部术后请先问医生"。

## 更新（v0.3.0）
- 文案支持中/英（按浏览器语言，默认中文）。
- 模态浮层改用 `--dsw-alias-bg-overlay` 表面、圆角/阴影对齐宿主观感；层级降为 1000，避免压住宿主提示。
- 切换会话/离开时自动收起浮层，不再残留。
- 到点提醒与「稍后 15 分钟」、离线/加载/已记录三态、Esc 关闭与焦点管理均保留。
